WaferLens v2: fab yield excursion detection and root cause, rebuilt from the v1 Streamlit demo (kept on the [`waferlens-v1-archive`](https://github.com/anson10/waferLens/tree/waferlens-v1-archive) branch).

> **Yield dropped. Which tool or chamber caused it, how early could we have known, and what does it look like on the wafer?**

Every detector is scored against the simulator's logged ground truth, next to a chance baseline, and every number below comes from a `make` target.

### Results
| Question | Result | Reproduce |
|---|---|---|
| How early could we have known? | Chamber EWMA/CUSUM alarm after a median **8–9 affected wafers**, against 33 for Shewhart (chance 140–200) | `make spc-report` |
| Which chamber caused it? | Commonality ranks the true cause **first for 72%** of excursions that cost yield (chance 0.8%) | `make rootcause-report` |
| What does it look like on the wafer? | FabEye patterns catch **13 of 13** spatial excursions SPC can't see, each traced to the right chamber | `make rootcause-report` |
| Can it run live? | Real-time SPC on Redpanda (Kafka API), exactly once through Postgres: a drift caught **after 3 points**, ~270 ms event to alarm | `make stream-demo` |
| Does it hold on real fab data? | UCI SECOM, time-ordered: PR-AUC 0.065 against chance 0.055; a random split **overstates the model 2.7×** | `make secom-model` |

Three excursions told end to end, from first alarm to dies lost: [docs/excursion_story.md](https://github.com/anson10/waferLens/blob/v2.0.0/docs/excursion_story.md) (`make story`).

### What's in it
- **Data:** a fab simulator with chamber-level wafer genealogy and an excursion ground-truth log (25,000 wafers, 4.8M rows; a stress profile at 24M), PostgreSQL 16 + TimescaleDB, an atomic COPY loader behind data contracts, and the real UCI SECOM dataset.
- **Pipeline:** dbt star schema (staging → intermediate → marts, tested), orchestrated as Dagster assets (`make pipeline`).
- **Analytics:** SPC (Western Electric, EWMA, CUSUM, Hotelling T²) on frozen Phase I limits, SQL commonality analysis, excursion impact, and pattern-led root cause.
- **Wafer maps** from [FabEye](https://github.com/anson10/FabEye) as a service; **SECOM fail prediction** tracked and registered in MLflow.
- **Serving:** six Grafana dashboards and two alert rules provisioned from git, Prometheus for FabEye, and a Power BI semantic model (PBIP: 39 DAX measures, row-level security, drillthrough, bookmarks).
- **Engineering:** 294 tests, CI on every PR, and 12 architecture decision records ([docs/](https://github.com/anson10/waferLens/blob/v2.0.0/docs/README.md)).

### Run it
```bash
cp .env.example .env && make install && make up
make pipeline   # one Dagster run, ~16 min
make story      # three excursions end to end
```
Needs Docker and uv. See the [README](https://github.com/anson10/waferLens/blob/v2.0.0/README.md#quickstart).
